How It Works

The Vigenère Cipher uses a repeating key to shift each letter of the plaintext.

Letter values:
A = 0, B = 1, C = 2, ... Z = 25

Encryption Formula:
C = (P + K) mod 26

Decryption Formula:
P = (C - K + 26) mod 26

Example

Plaintext: H

Key: E

H = 7 and E = 4

(7 + 4) mod 26 = 11

11 = L

Therefore: H + E → L
